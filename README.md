## 团队填写顺序

1. **核对资格和证明。** 核对本次作品申报资格、前期成果使用权限与成员信息。向学院确认本次申报范围是否需要医疗卫生证明。
2. **核对题目和内容。** 检查报名表、开题报告和支撑 PDF 的题目、B 类申报信息、已有功能与拟开展工作是否一致。
3. **最后合包。** 用官方模板填报，核查签字节点、正文匿名和附件可打开性。团队成员的学号、手机号、签字文件和完整提交包在团队约定的安全渠道汇总。

当前有报名表填写稿、匿名开题初稿和选交支撑 PDF，供组内核对。报名表的负责人最高学历、成员和导师信息留空。组内核对后，在正式提交副本补齐实名信息及签字。
