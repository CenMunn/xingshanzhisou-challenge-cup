## 团队填写顺序

1. **先核资格。** 查两项旧赛事的实际获奖级别，梳理前期成果归属和队伍成员实际分工。把本次作品的具体功能发给学院确认医疗卫生证明口径。
2. **同步写开题。** 技术组核对旧版已完成与本次拟新增的功能，评测组先定对照和指标。组长统一作品题目、类别与 500 字报名简介。
3. **最后合包。** 用官方模板填报，核查签字节点、正文匿名和附件可打开性。团队成员的学号、手机号、签字文件和完整提交包在团队约定的安全渠道汇总。

此仓库当前存放备赛资料和空白模板。报名表、正式开题报告和签字承诺书待团队按实际信息完成，是否提交由组长核对。
